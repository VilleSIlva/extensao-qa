## Cenário 20: Cadastros auxiliares na plataforma SIFIT.

### Caso de Teste 01: Cadastro de Bandeiras de Cartão com o formulário vazio.

| ID | Descrição |
| :--- | :--- |
| C20-CT01 | Verificar se o sistema impede o cadastro de Bandeiras de Cartão sem nome e informa o campo obrigatório. |

| **Pré-condições** |
| :--- |
| O usuário deve estar autenticado na plataforma SIFIT. |

| **Passos** |
| :--- |
| **DADO** que acessamos a tela "Bandeiras de Cartão" |
| **E** clicamos no botão "Nova Bandeira" |
| **E** mantemos todos os campos vazios |
| **QUANDO** clicarmos no botão "Salvar" |
| **ENTÃO** o sistema deverá informar o campo obrigatório e não criar o registro |

| **Critérios de aceitação** |
| :--- |
| O sistema deve bloquear o salvamento, informar o campo obrigatório e não criar registro em branco nem retornar erro do servidor. |
